# User Management System

A full-stack User Management System built using Flask, PostgreSQL, Docker, HTML, CSS, and JavaScript.

## 🚀 Features

- Add new users
- View all users
- Edit existing users
- Delete users
- REST API using Flask
- PostgreSQL database
- Dockerized backend and database
- Simple responsive frontend

## 🛠️ Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- PostgreSQL
- Docker
- HTML
- CSS
- JavaScript
- REST API
